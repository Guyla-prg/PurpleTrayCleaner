# PurpleTrayCleaner

NCsoft **Purple**（JP / TW 版対応）および **Purple ON** がバージョンアップのたびに Windows 11 の「その他のシステムトレイアイコン」へ古いバージョンのアイコンを登録し続ける問題に対処するツールです。

**現在動作中の Purple / Purple ON 以外の古い登録だけを削除**できます。

## ダウンロード

右側の **Releases**（または [Latest Release](https://github.com/Guyla-prg/PurpleTrayCleaner/releases/latest)）から `PurpleTrayCleaner.exe` をダウンロードしてください。

- 単一の `.exe` ファイルのみで動作します（追加インストール不要）。
- 対応 OS: **Windows 11**（22H2 以降）

> **初回起動時に「Windows によって PC が保護されました」と表示された場合**
> 個人作成の未署名アプリのため Windows SmartScreen の警告が出ることがあります。**「詳細情報」→「実行」** をクリックして起動してください。

## 使い方

1. **Purple / Purple ON を起動した状態**で `PurpleTrayCleaner.exe` をダブルクリックします。
2. 動作中のものは緑色（保持・チェック OFF）、未動作の古い登録は削除候補（チェック ON）として一覧表示されます。
3. 内容を確認し、**「選択項目を削除」** ボタンをクリックします。
4. Windows の設定画面（「設定」→「個人用設定」→「タスクバー」→「その他のシステムトレイアイコン」）へすぐ反映したい場合は、**「エクスプローラー再起動」** ボタンを押すか PC を再起動してください。

## 安全対策

- **対象限定:** `Purple.exe` / `purpleon.exe` のトレイ登録のみを対象にし、ゲーム本体や他社アプリは一切変更しません。
- **自動バックアップ:** 削除前に必ず `.reg` 形式のバックアップを `%LOCALAPPDATA%\PurpleTrayCleaner\backups\` へ自動保存します（ダブルクリックで復元可能）。
- **動作中保護:** 管理者権限で動作している Purple / Purple ON も検出し、現在動作中のバージョンを保護します。

## コマンドラインオプション（自動実行向け）

タスクスケジューラ等から自動実行したい場合は以下のオプションが使えます。

- `--dry-run` : 削除を行わず、スキャン結果と削除候補を確認
- `--auto` : GUI を出さずに動作中以外を自動削除（動作中が 0 件のときは安全のためスキップ）
- `--auto --restart-explorer` : 1 件以上削除した場合に `explorer.exe` も自動で再起動
